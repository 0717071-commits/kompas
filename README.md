# Компас ценностей

Веб-упражнение для психологов, работающих в терапии принятия и ответственности (ACT).
Клиент получает ссылку, сам между сессиями отмечает 10 сфер жизни по двум шкалам
(важность и действия за неделю), выбирает 1–3 сферы, формулирует, каким хочет быть в каждой,
и планирует маленький шаг на неделю. Итог отправляет психологу ссылкой, картинкой или текстом.

## Принципы

- **Без сервера.** Статический сайт: HTML, CSS и JavaScript без сборщиков и фреймворков.
- **Приватность.** Ответы хранятся только в `localStorage` браузера клиента. Нет аналитики,
  cookie и запросов к сторонним сервисам: шрифты и библиотека сжатия лежат в репозитории.
- **Ссылка-результат.** Ответы сжимаются [lz-string](https://github.com/pieroxy/lz-string)
  и записываются в адрес после `#r=`. Эта часть адреса не уходит на сервер; психолог открывает
  ссылку и видит итог только для чтения, не затирая собственные данные браузера.
- **Картинка PNG** рисуется на `<canvas>` вручную: роза сфер, ценности и шаги, без html2canvas.
- **Мобильная версия в приоритете:** крупные ползунки, нижняя панель с учётом safe-area,
  системное меню «Поделиться» на телефоне.

## Структура

```
index.html            упражнение
psychologist.html     страница «Для психолога»
css/style.css         оформление, светлая и тёмная темы
js/app.js             состояние, экраны, навигация, роза сфер
js/share.js           упаковка ответов в ссылку и режим просмотра
js/png.js             итог картинкой
js/config.js          пути к иллюстрациям из img/
js/vendor/            lz-string 1.5.0
fonts/                Golos Text, Cormorant Garamond (OFL)
img/                  иллюстрации
```

## Запуск локально

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.
